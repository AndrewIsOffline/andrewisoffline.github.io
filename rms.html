Restaurant Management System

Restaurant Management System was the result of a weeks-long collaborative project as part of a software engineering class. It includes functionality for making menus, managing waitstaff, and keeping track of tables and orders.

As part of the project, I designed the UI and file manager, along with an automated QA test, while a teammate designed the backend. Below is the main UI file.
